# نمونه‌سازی شاخص ماتریس کاشی

**وضعیت:** نمونه‌سازی ریاضی غیرتولیدی برای ADR-0001. این کد ماتریس، payload، URL/API یا سقف بزرگ‌نمایی محصول GeoCore را انتخاب نمی‌کند.

## پرسش آزموده‌شده

در نامزد Web Mercator XYZ، آیا تبدیل طول/عرض به اندیس کاشی و وارون‌سازی ردیف XYZ↔TMS در لبه‌های جهان، حد تصویر، بزرگ‌نمایی صفر و ورودی نامعتبر سازگار است؟

## اجرا

از Bun 1.4.5، TypeScript Strict نسخه 7.0.2 و Vitest نسخه 5.1.1 استفاده می‌کند. وابستگی‌ها را از فایل قفل نصب و بررسی نوع و آزمون‌ها را اجرا کنید:

```sh
bun install --frozen-lockfile
bun run check
```

## نتیجه مشاهده‌شده

بررسی TypeScript Strict و هر هفت آزمون Vitest در محیط کنونی موفق شدند (Bun 1.4.5). آزمون‌ها کاشی مبدأ در z0، خانه استوا/نصف‌النهار در z1، رفتار لبه طول ±۱۸۰ درجه، محدودکردن عرض جغرافیایی به Mercator، خاصیت وارون‌پذیری تبدیل XYZ/TMS برای نمونه‌های مرزی/میانی و رد بزرگ‌نمایی/مختصات نامعتبر را بررسی می‌کنند.

## معنای صریح این نمونه

- ورودی طول جغرافیایی سپس عرض جغرافیایی بر حسب درجه است؛ این ماژول parser GeoJSON یا قرارداد سرویس نیست.
- عرض به حد ریاضی Web Mercator برابر ±85.0511287798066 درجه محدود می‌شود.
- طول +۱۸۰ درجه به آخرین ستون کاشی نگاشت می‌شود، نه اندیس خارج محدوده x=n؛ مقدار خارج از بازه [-۱۸۰، ۱۸۰] رد می‌شود و wrap نمی‌شود.
- آزمون فقط برای عددهای صحیح z از ۰ تا ۳۰ اجرا می‌شود؛ این سقف محصول نیست.
- مبدأ ردیف XYZ شمال/بالا است؛ تبدیل TMS مقدار y را با `2^z - 1 - y` وارونه می‌کند.

اینها فرض‌های آزمون‌اند، نه رفتار نهایی محصول. رفتار قطب جغرافیایی، پادنصف‌النهار، فرافکنی دیگر، اعتبارسنجی API آینده و استاندارد ماتریس نیازمند بازبینی مالک/فنی است.

## مواردی که آزمون نشده‌اند

این نمونه MVT یا payload دیگری تولید نمی‌کند، MapLibre را رندر نمی‌کند، فونت/برچسب را نمی‌آزماید، داده OSM واقعی ندارد، مجوز را بررسی نمی‌کند، قالب ذخیره را انتخاب نمی‌کند، HTTP، مجوز دسترسی یا Cache پیاده‌سازی نمی‌کند و عملکرد را اندازه نمی‌گیرد. مقایسه کامل قالب/API/ذخیره‌سازی در ADR-0001 همچنان باز است. این نتیجه ادعای پوشش یا آمادگی تولید نیست.
