# نمونه سازگاری Fastify و Zod

**وضعیت:** آزمون سازگاری جدا و غیرتولیدی برای پشته توسعه‌ای که مالک محصول تعیین کرده است. این نمونه endpoint، قرارداد API، سیاست احراز هویت، مدل استقرار یا adapter تولیدی GeoCore را تعریف یا انتخاب نمی‌کند.

## پرسش و روش

آیا API کوچکی با Fastify زیر Bun، TypeScript Strict و Vitest اجرا می‌شود و همان شِماهای Zod هم اعتبارسنجی درخواست/پاسخ در زمان اجرا و هم نوع‌های استنتاج‌شده handler را فراهم می‌کنند؟

نمونه از `fastify-type-provider-zod` به‌عنوان اتصال نامزد استفاده می‌کند. Vitest از قابلیت تزریق درون‌فرایندی Fastify استفاده می‌کند؛ پورت شبکه باز نمی‌کند و داده شخصی، OSM یا تولیدی به‌کار نمی‌برد. آزمون‌ها درخواست معتبر، درخواست ناسازگار با شِما، نوع زمان‌اجرای نادرست و رد پاسخ ناسازگار با شِمای Zod را می‌سنجند. TypeScript بررسی می‌کند که نوع ورودی handler از شِمای Zod استنتاج شده باشد.

## اجرا

نسخه‌های Bun 1.4.5، TypeScript 7.0.2 و Vitest 5.1.1 در فایل بسته/قفل همراه Fastify 5.12.8، `fastify-type-provider-zod` نسخه 7.0.0 و Zod نسخه 4.6.7 تثبیت شده‌اند:

```sh
bun install --frozen-lockfile
bun run check
bun run audit
```

## نتیجه مشاهده‌شده

بررسی TypeScript Strict موفق است و هر پنج آزمون Vitest زیر Bun 1.4.5 می‌گذرند. payload نامعتبر در این نمونه پاسخ HTTP 400 می‌گیرد؛ ورودی معتبر به handler می‌رسد که نوع ورودی آن از شِمای Zod استنتاج شده است. Bun audit هنگام اجرا برای درخت وابستگی تولیدی قفل‌شده آسیب‌پذیری شناخته‌شده‌ای گزارش نکرد.

بسته‌های مستقیم پشته API مجوز MIT اعلام می‌کنند. فایل قفل Bun نسخه‌ها و داده یکپارچگی را ثبت می‌کند، اما سیاهه کامل مجوز وابستگی‌ها نیست. این نتیجه تأیید حقوقی، بازبینی کامل مجوز وابستگی، تضمین نبود آسیب‌پذیری آینده یا اثبات مناسب‌بودن adapter برای تولید نیست.

## چه چیزهایی آزموده یا انتخاب نشده‌اند

شنونده سرور/رفتار شبکه، احراز هویت یا مجوز دسترسی، جداسازی سازمان/مستأجر، محدودیت درخواست، محدودیت نرخ، قرارداد خطا، نسخه‌بندی API، خروجی OpenAPI، استقرار تولیدی، ثبت/حذف اطلاعات حساس، بار، بازیابی خرابی یا همکاری با سرویس‌ها ارزیابی نشده‌اند. هیچ adapterی برای تولید تصویب نشده است. پیش از استفاده در سرویس واقعی، نسخه‌های پشتیبانی‌شده Fastify/Zod، نگهداری، امنیت و مجوز ادغام دوباره بررسی شوند.
