# نمونه‌سازی رمزگذاری و بازخوانی MVT

**وضعیت:** ارزیابی نامزد جدا و غیرتولیدی برای ADR-0001. Mapbox Vector Tile فقط به‌عنوان نامزد payload آزمایش می‌شود؛ این کار آن را برای GeoCore انتخاب نمی‌کند و API ارائه را تعریف نمی‌کند.

## چه چیزی آزموده می‌شود

یک FeatureCollection مصنوعی GeoJSON که در مخزن است و عارضه‌های نقطه، خط و چندضلعی دارد، با `geojson-vt` به کاشی برش داده، با `vt-pbf` رمزگذاری و با `@mapbox/vector-tile` و `pbf` بازخوانی می‌شود. آزمون‌ها فراداده لایه، نوع هندسه، شناسه عددی عارضه، ویژگی‌های UTF-8 انگلیسی/فارسی، نشانگر داده مصنوعی و برش خط و چندضلعی در دو کاشی XYZ همسایه را بررسی می‌کنند. مختصات کاشی نامعتبر رد می‌شوند.

## اجرا

از Bun 1.4.5، TypeScript Strict نسخه 7.0.2 و Vitest نسخه 5.1.1 استفاده می‌کند. وابستگی‌ها در `package.json` و `bun.lock` همین نمونه مجزا تثبیت شده‌اند:

```sh
bun install --frozen-lockfile
bun run check
bun run audit
```

این فایل بسته، ابزار نهایی سرویس تولیدی GeoCore را تصویب نمی‌کند.

## نتیجه فعلی

بررسی TypeScript Strict و هر هشت آزمون Vitest در محیط فعلی موفق‌اند (Bun 1.4.5). بایت‌های رمزگذاری‌شده به لایه MVT نسخه ۲ با extent برابر ۴۰۹۶ بازخوانی می‌شوند و نوع هندسه، شناسه‌ها و ویژگی‌های انتخاب‌شده حفظ می‌شوند؛ خط و چندضلعی مصنوعی در دو کاشی آزمون همسایه برش‌خورده دیده می‌شوند و حلقه‌های چندضلعیِ برش‌خورده بسته می‌مانند؛ ساخت‌های تکراری بایت یکسان تولید می‌کنند و کاشی فاقد عارضه صریح گزارش می‌شود. داده فقط مصنوعی است و OSM واقعی یا موقعیت شخصی ندارد. نسخه/extent این نمونه پارامتر آزمون‌اند، نه انتخاب محصول.

بسته‌های مستقیم: `geojson-vt` نسخه 5.0.4 با مجوز ISC، `vt-pbf` نسخه 3.1.3 با مجوز MIT، `@mapbox/vector-tile` نسخه 3.0.0 با مجوز BSD-3-Clause و `pbf` نسخه 5.2.0 با مجوز BSD-3-Clause. فایل `bun.lock` نسخه و داده یکپارچگی وابستگی‌های حل‌شده را تثبیت می‌کند، اما سیاهه مجوزهای وابستگی‌های انتقالی نیست. Bun audit هنگام بررسی درخت وابستگی‌های تولیدیِ قفل‌شده، آسیب‌پذیری شناخته‌شده‌ای گزارش نکرد. این نتیجه تأیید حقوقی، نظر کامل مجوز، گواهی زنجیره تأمین یا تضمین در برابر هشدارهای آینده نیست؛ پیش از استفاده تولیدی، مجوزها و هشدارها دوباره بررسی شوند.

## چه چیزهایی آزموده یا انتخاب نشده‌اند

نمایش در MapLibre، تنظیم منبع/سبک، معنای جایگزینی نام، تحویل glyph/فونت، برش حفره و چندضلعی چندبخشی، ماتریس/API کاشی، رفتار HTTP، فایل داده، ذخیره، Cache، مجوز دسترسی، جداسازی سازمان، هر دو مدل میزبانی، استخراج واقعی OSM، انتساب، عملکرد و سقف منابع تولیدی آزموده نشده‌اند. بازگشت UTF-8 ویژگی‌ها **نمایش صحیح یا پشتیبانی زبانی را ثابت نمی‌کند**. ADR-0001 و دروازه‌های انتشار همچنان بازند.
