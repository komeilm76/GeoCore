# نمونه‌سازی رمزگذاری و بازخوانی MVT

**وضعیت:** ارزیابی نامزد جدا و غیرتولیدی برای ADR-0001. Mapbox Vector Tile فقط به‌عنوان نامزد payload آزمایش می‌شود؛ این کار آن را برای GeoCore انتخاب نمی‌کند و API ارائه را تعریف نمی‌کند.

## چه چیزی آزموده می‌شود

یک FeatureCollection مصنوعی GeoJSON که در مخزن است و عارضه‌های نقطه، خط و چندضلعی دارد، با `geojson-vt` به کاشی برش داده، با `vt-pbf` رمزگذاری و با `@mapbox/vector-tile` و `pbf` بازخوانی می‌شود. آزمون‌ها فراداده لایه، نوع هندسه، شناسه عددی عارضه، ویژگی‌های UTF-8 انگلیسی/فارسی، نشانگر داده مصنوعی و برش خط و چندضلعی در دو کاشی XYZ همسایه را بررسی می‌کنند. مختصات کاشی نامعتبر رد می‌شوند.

## اجرا

از Bun 1.4.5، TypeScript Strict نسخه 7.0.2 و Vitest نسخه 5.1.1 استفاده می‌کند. وابستگی‌ها در `package.json` و `bun.lock` همین نمونه مجزا تثبیت شده‌اند:

```sh
bun install --frozen-lockfile
bun run check
bun run audit
```

این فایل بسته، ابزار نهایی سرویس تولیدی GeoCore را تصویب نمی‌کند.

## نتیجه فعلی

بررسی TypeScript Strict و هر سیزده آزمون Vitest در محیط فعلی موفق‌اند (Bun 1.4.5). بایت‌های رمزگذاری‌شده به لایه MVT نسخه ۲ با extent برابر ۴۰۹۶ بازخوانی می‌شوند و نوع هندسه‌های نقطه/خط/چندضلعی/چندضلعی چندبخشی، شناسه‌ها و ویژگی‌های انتخاب‌شده حفظ می‌شوند؛ خط و چندضلعی مصنوعی در دو کاشی آزمون همسایه برش‌خورده دیده می‌شوند و حلقه‌های خارجی بسته می‌مانند؛ حفره‌ای که کاملاً در یک کاشی قرار دارد هنگام برش حلقه خارجی حفظ می‌شود و یک جزء جداگانه چندضلعی چندبخشی نیز تفکیک‌شده می‌ماند؛ ساخت‌های تکراری بایت یکسان تولید می‌کنند و کاشی فاقد عارضه صریح گزارش می‌شود. آزمون‌های جداگانه شِمای سبک حداقلی MapLibre را اعتبارسنجی، `source-layer` را بررسی و وجود ارجاع‌های `get` سبک را میان عارضه‌های لایه منبع رمزگذاری‌شده می‌سنجند؛ ویژگی عمداً غایب نشان می‌دهد این بررسی ناسازگاری‌هایی را می‌یابد که شِمای سبک به‌تنهایی نمی‌گیرد. داده فقط مصنوعی است و OSM واقعی یا موقعیت شخصی ندارد. نسخه/extent این نمونه پارامتر آزمون‌اند، نه انتخاب محصول.

بسته‌های مستقیم تولیدی: `geojson-vt` نسخه 5.0.4 با مجوز ISC، `vt-pbf` نسخه 3.1.3 با مجوز MIT، `@mapbox/vector-tile` نسخه 3.0.0 با مجوز BSD-3-Clause و `pbf` نسخه 5.2.0 با مجوز BSD-3-Clause.

اعتبارسنج سبک فقط ابزار توسعه نامزد است: `@maplibre/maplibre-gl-style-spec` نسخه 26.9.0. فراداده npm/بسته مجوز ISC اعلام می‌کند، اما نشان مجوز README می‌گوید BSD-3-Clause و فایل مجوز توزیع‌شده شامل شروط BSD-3-Clause و بخشی قدیمی از Mapbox است. این ناسازگاری حل نشده؛ نتیجه‌گیری حقوقی یا تأیید تولیدی نیست. بسته فقط برای ارزیابی جداگانه شِمای سبک نگه داشته شده است. استانداردکردن آن یا گنجاندنش در خروجی تولیدی/توزیعی تا حل اختلاف با بازبینی مجوز واجدصلاحیت مسدود است.

فایل `bun.lock` نسخه و داده یکپارچگی وابستگی‌های حل‌شده را تثبیت می‌کند، اما سیاهه مجوزهای وابستگی‌های انتقالی نیست. Bun audit کل درخت وابستگی قفل‌شده، از جمله ابزارهای توسعه، هنگام اجرا آسیب‌پذیری شناخته‌شده‌ای گزارش نکرد. این نتیجه تأیید حقوقی، نظر کامل مجوز، گواهی زنجیره تأمین یا تضمین در برابر هشدارهای آینده نیست؛ پیش از استفاده تولیدی، مجوزها و هشدارها دوباره بررسی شوند.

## چه چیزهایی آزموده یا انتخاب نشده‌اند

رندر واقعی در MapLibre، اعمال واقعی سبک، نمایش جایگزینی نام، تحویل glyph/فونت، برش عمومی حفره و چندضلعی چندبخشی (یک مورد حفره و یک مورد برش مؤلفه چندضلعی چندبخشی آزموده شده‌اند)، ماتریس/API کاشی، رفتار HTTP، فایل داده، ذخیره، Cache، مجوز دسترسی، جداسازی سازمان، هر دو مدل میزبانی، استخراج واقعی OSM، انتساب، عملکرد و سقف منابع تولیدی آزموده نشده‌اند. فقط شِمای سبک نامزد و ارجاع برخی ویژگی‌ها بررسی می‌شود؛ MapLibre هیچ کاشی‌ای بارگیری نمی‌کند. بازگشت UTF-8 ویژگی‌ها **نمایش صحیح یا پشتیبانی زبانی را ثابت نمی‌کند**. ADR-0001 و دروازه‌های انتشار همچنان بازند.
