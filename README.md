## Project status

**Planning and foundation only.** There is currently no service implementation, API contract, deployable artifact, production dataset, or release commitment in this repository. Proposed architecture and work items are explicitly labeled as proposals until reviewed and approved. Do not use this repository as a production map-data endpoint.

## Working principles

Requirements and decisions are traceable, security and licensing are release gates, Persian and English product documentation must be version-aligned, and services must not depend on installing other GeoCore services unless explicitly approved. See [governance](docs/global/GOVERNANCE.md), [architecture](docs/global/ARCHITECTURE.md), the [development stack baseline](docs/global/DEVELOPMENT-STACK.md), and [security](docs/global/SECURITY.md).
