# Decision records

Architecture Decision Records (ADRs) record technical choices; they do not create product approval or override law, licenses, security requirements, or product scope. There are currently **no accepted architecture decisions**. ADR-0001 is a proposed, not-yet-approved plan to compare vector-tile delivery options; it does not select a format or API.

Create a record by copying [the ADR template](TEMPLATE.md) to `NNNN-short-title.md`; provide a Persian companion `NNNN-short-title.fa.md` for product-facing decisions. Assign the next number only after checking this directory. Begin with `proposed`; change to `accepted` only when the accountable approvers are recorded. Link the ADR from [the ADR index](../global/ADRS.md), the relevant service manual and [requirements traceability](../global/REQUIREMENTS-TRACEABILITY.md). Superseded records remain in history.

Current proposal: [ADR-0001 in English](0001-vector-tile-delivery-contract.md) · [نسخه فارسی](0001-vector-tile-delivery-contract.fa.md).

An unresolved decision with no approved owner or rationale must remain open. Do not treat a draft, code default, dependency availability or this template as a decision.
