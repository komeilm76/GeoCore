# Internationalization and bilingual documentation

**Required product languages:** Persian (`fa`) and English (`en`). English is the documented default only after explicit request and acceptable client preference rules are applied. These requirements apply to released product text and manuals; a source-data name without a translation is not a product translation.

## Content and behavior

- Inventory all GeoCore-generated labels, errors, statuses, notifications, manager text and offered route instructions. Maintain identical stable keys and interpolation parameters in both languages and human-review semantic equivalence.
- Keep identifiers, error codes, JSON keys and machine numbers locale-independent. Return the actual language of source names when known; use `unknown` rather than guessing. Mark fallback names as fallback, not as translations.
- Normalize Persian/Arabic kaf and yeh variants, digits, spaces and half-spaces for comparison/indexing only. Preserve original input and source text; test false-match risks. Define English casing and whitespace rules.
- Support RTL Persian and LTR English. Isolate mixed-direction URLs, code, coordinates and foreign names; test shaping, fonts, copy/paste, map labels and accessibility in every declared environment.
- Separate language-sensitive caches. Do not put private responses into shared caches merely by adding language to the cache key.
- Declare language selection precedence, invalid-tag behavior and actual response language in the service contract; do not silently translate data names.

## Documentation release rule

Every releasable version includes matching Persian and English quick start, install/configuration, API reference, examples, error/security guidance, limitations, changes and upgrade/support information. Examples run against that exact version. Both language reviews are a release gate. This product repository currently contains draft requirements and manuals, not evidence of released service capability.

## Review checklist

- [ ] Message inventory and keys match in `fa` and `en`.
- [ ] Parameters, plural/status variants and error codes match.
- [ ] Human and technical reviewers approve semantic parity.
- [ ] RTL/LTR, mixed text, fonts, Persian normalization and copy/paste tested.
- [ ] Untranslated names and language fallback are honestly identified.
- [ ] Language-specific cache behavior verified; private cache policy separately checked.
- [ ] User and operator docs, diagrams, examples, screenshots and release notes updated together.
