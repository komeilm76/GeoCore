# GeoCore glossary / واژه‌نامه GeoCore

| English term | فارسی پیشنهادی | Meaning / یادداشت |
|---|---|---|
| Base data | داده پایه | Licensed reference dataset with source, extent and version. |
| Coverage | پوشش | Geographic and subject-matter extent offered; unknown coverage is not “no feature.” |
| Freshness | تازگی | Observation/validity time relative to use, distinct from receipt/publication. |
| Direct distance | فاصله مستقیم | Geographic point-to-point distance, not network distance. |
| Network distance | فاصله شبکه | Distance over traversable network. |
| Planned trip | سفر برنامه‌ریزی‌شده | Requested route and its result. |
| Recorded trip / history | سفر ثبت‌شده / تاریخچه | Actual accepted observations; not a planned route or proof of unsampled path. |
| Stop / destination | توقف / مقصد | Input visit point; duplicate coordinates do not erase distinct input identity. |
| Leg | بخش مسیر | Portion between consecutive points in final planned order. |
| ETA | زمان تخمینی رسیدن | Estimate based on available inputs at calculation time; not a guarantee. |
| Stale | قدیمی | Location/data has exceeded approved freshness threshold; not current/live. |
| Unknown | نامعلوم | Evidence is insufficient; do not silently convert to zero, empty or false certainty. |
| Tenant | مستأجر / دامنه سازمانی | Security boundary for an organization/consumer; exact product term awaits glossary review. |
| Data version | نسخه داده | Immutable/identifiable dataset release used for a response or operation. |

This is an initial working glossary. Persian terminology requires human and technical review before product release, as required by `I18N-08`.
