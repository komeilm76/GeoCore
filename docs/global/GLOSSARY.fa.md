# واژه‌نامه GeoCore

ترجمه‌پیش‌نویس این واژه‌نامه است؛ اصطلاح‌های فارسی باید پیش از انتشار توسط بازبین انسانی و فنی تأیید شوند.

| اصطلاح انگلیسی | برابر فارسی پیشنهادی | معنی و یادداشت |
|---|---|---|
| Base data | داده پایه | مجموعه مرجع مجاز با منبع، گستره و نسخه معلوم. |
| Proprietary data | داده اختصاصی | داده یا تغییر متعلق به یک مصرف‌کننده؛ جداسازی فنی به‌تنهایی انطباق مجوز را تضمین نمی‌کند. |
| Coverage | پوشش | گستره جغرافیایی و موضوعی عرضه‌شده؛ پوشش نامعلوم یعنی «عارضه وجود ندارد» نیست. |
| Freshness | تازگی | زمان مشاهده/اعتبار نسبت به استفاده؛ با دریافت یا انتشار یکی نیست. |
| Direct distance | فاصله مستقیم | فاصله جغرافیایی نقطه‌به‌نقطه، نه فاصله مسیر شبکه. |
| Network distance | فاصله شبکه | طول مسیر قابل عبور روی شبکه. |
| Planned trip | سفر برنامه‌ریزی‌شده | درخواست مسیر و نتیجه آن. |
| Recorded trip / history | سفر ثبت‌شده / تاریخچه | مشاهده‌های واقعی پذیرفته‌شده؛ مسیر برنامه‌ریزی‌شده یا اثبات راهِ نمونه‌برداری‌نشده نیست. |
| Stop / destination | توقف / مقصد | نقطه بازدید ورودی؛ مختصات تکراری هویت ورودی مستقل را حذف نمی‌کند. |
| Leg | بخش مسیر | قسمت میان دو نقطه متوالی در ترتیب نهایی برنامه. |
| ETA | زمان تخمینی رسیدن | برآورد بر اساس ورودی زمان محاسبه، نه تضمین. |
| Stale | قدیمی | داده از آستانه تازگی مصوب گذشته و نباید جاری/زنده معرفی شود. |
| Unknown | نامعلوم | شواهد کافی نیست؛ به صفر، نتیجه خالی یا قطعیت کاذب تبدیل نشود. |
| Tenant | دامنه سازمانی | مرز امنیتی مصرف‌کننده/سازمان؛ اصطلاح نهایی فارسی نیازمند بازبینی واژه‌نامه است. |
| Data version | نسخه داده | نسخه قابل شناسایی مجموعه استفاده‌شده در پاسخ یا پردازش. |
